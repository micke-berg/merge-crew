# Merge Crew

A free browser game that teaches git. You lead a crew of small robot coding agents who all work in the same repository, and they make the mistakes real coding agents make: force-pushes over other people's work, branches that drift far from main, work that never gets committed. You fix it with real git commands, and later you set the rules that stop it from happening.

Status: early development. See `docs/spec.md` for what version 1 contains.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
